stream alignment changed, so no cross-version paired interval is claimed.

V2 treated an aggregate residual-produced sibling as owned by the whole
residual mass. V3 always gamma-splits the residual ocean during target races.

profitable, and 12 inconclusive environments in v2 to 33 profitable, 42 not
profitable, and 15 inconclusive in v3. The standard selfish-mining benchmark,
which v2 failed materially, matches all 15 tested theoretical cases in v3.

coalition. V3 contains 33 profitable environments: one has weak joint
feasibility, none has strict joint feasibility, and 32 have no feasible
coalition in the tested grid. The sole weak result is alpha 0.20, gamma 1,
lambda 0 at active hash 0.30, with six tied compositions and zero credibility

All substantive conclusions use v3 only. V2 is retained solely for audit.
